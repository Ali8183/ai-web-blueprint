## Discovery Paths & Scopes

1. **Managed / Organization Policy:** `/etc/claude-code/CLAUDE.md` (or OS enterprise equivalent).
2. **User Personal Memory:** `~/.claude/CLAUDE.md`.
3. **Shared Project Memory (Checked into Git):** `./CLAUDE.md`, `./.claude/CLAUDE.md`, or `AGENTS.md`.
4. **Private Local Override (Gitignored):** `./CLAUDE.local.md`.
5. **Path-Scoped Rules (Optional):** `.claude/rules/*.md` with frontmatter `paths:` globs.

## Precedence & Adherence Notes

- Discovered memory files across hierarchy levels are concatenated into session context; more specific/local instructions refine project context, while Anthropic notes memory files act as soft guidance (hard command/safety blocks belong in hooks or CI gates).
- Anthropic recommends keeping root `CLAUDE.md` concise (`<= 200` lines) so instructions stay salient; therefore `CLAUDE.md` in this repo is generated by `scripts/sync-adapters.mjs` as a short pointer to `AGENTS.md`, exact `npm` scripts, `standards/`, and `presets/`.
- Because Claude Code natively reads `CLAUDE.md` at session start (while `AGENTS.md` support may vary by workflow), keeping a thin synced `CLAUDE.md` guarantees clean discovery without duplicating policy text.
