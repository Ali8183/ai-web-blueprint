# Adapter: Antigravity

- **Official Discovery Docs Verified:** Antigravity built-in customization documentation (`agy-customizations` skill docs) & `https://antigravity.google/docs` (reviewed 2026-11-16).
- **Testing Status:** Verified in this active Antigravity runtime against built-in customization schemas; see [adapters/README.md](./README.md).

## Discovery Paths & Scopes

1. **Workspace Project Rules (Hierarchical):**
   - `GEMINI.md` and `AGENTS.md` in repository root and intermediate directories (walking up from active working directory to repository root containing `.git`).
   - `.agents/rules/*.md` (specifically `.agents/rules/core-guardrails.md`, kept strictly under the `24,000`-byte per-file cap and within the `20,000`-token aggregate rules budget).
2. **Workspace Skills (Progressive Disclosure):**
   - `.agents/skills/<skill-name>/SKILL.md` with required YAML frontmatter `name` and `description`.
   - Only `name` and `description` load upfront; full `SKILL.md` instructions load on demand when activated by task context.
3. **Global User Config (Machine-local, outside repo):**
   - `~/.gemini/config/` (lower precedence than workspace project rules).

## Precedence & Deduplication

1. Workspace project hierarchical discovery (CWD up to repo root) — **highest project priority**
2. Declared `skills.json` / `plugins.json` in workspace (not needed here because `.agents/` auto-discovers)
3. Global discovery (`~/.gemini/config/`)
4. Built-in customizations

Rules are deduplicated by resolved file path so matching multiple discovery paths never injects duplicates in a turn.
